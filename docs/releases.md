# Releases

A release publishes the version in `plugin.json`:

1. Set `version` in `plugin.json` and run `tools/bin/plugin generate` (the Swift package embeds the version).
2. Commit and push to the default branch.
3. Run the **Release** workflow (Actions tab, or `gh workflow run release.yml`).

The workflow builds the Android AAR on Linux and the iOS XCFramework on macOS. Then it creates a GitHub
release named `<id>-<version>` (for example `ngon-layer-0.1.0`) with a tag named after the version (for
example `0.1.0`) at the built commit. The release contains:

- usage instructions for Android and iOS, generated by `tools/bin/plugin release-notes`, followed by the
  list of changes
- `<artifactId>-<version>.aar` and `<Product>-<version>.xcframework.zip`, each with a `.sha256` file

Finally it requests the version from [JitPack](https://jitpack.io), which builds the Android library from
the tag with `jitpack.yml` (installed by `sync`), and fails if JitPack can't publish it.

The workflow refuses to overwrite an existing release. Versions with a pre-release suffix, such as
`0.2.0-pre1`, are marked as pre-releases.

## Using a released plugin in an app

Apps must use the plugin-enabled SDK versions from the tools' [`versions.json`](../versions.json) that the
plugin was built with. Each release's notes contain these instructions with the exact versions.

### Android (JitPack)

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven("https://jitpack.io")
    }
}

// build.gradle.kts
dependencies {
    implementation("org.maplibre.gl:android-sdk-vulkan:<versions.maplibreAndroid>") // or android-sdk-opengl
    implementation("com.github.<owner>:<plugin-repository>:<version>")
}
```

Register after initializing MapLibre and before loading a style:

```kotlin
MapLibre.getInstance(context)
SquareLayerPlugin.register()
```

### iOS (Swift Package Manager)

```swift
dependencies: [
    .package(url: "https://github.com/louwers/maplibre-ios-with-plugin-api", exact: "<versions.maplibreIos>"),
    .package(url: "https://github.com/<owner>/<plugin-repository>", exact: "<version>"),
],
targets: [
    .target(name: "App", dependencies: [
        .product(name: "MapLibre", package: "maplibre-ios-with-plugin-api"),
        .product(name: "SquareLayer", package: "<plugin-repository>"),
    ]),
]
```

In Xcode, add both packages with File > Add Package Dependencies.

```swift
import MapLibre
import SquareLayer

try SquareLayerPlugin.registerPlugin()
```

The release also contains a static `<Product>.xcframework`, for apps that don't use Swift Package Manager.
It contains only the plugin: it resolves `mln_plugin_register_v1` from the MapLibre framework, and its
module map links libc++ and Foundation.
